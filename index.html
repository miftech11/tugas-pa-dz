Tentang Coding Club

Coding Club SMKN 1 Subang dibentuk dengan tujuan untuk memberikan wadah belajar pemrograman bagi siswa yang memiliki minat di bidang teknologi. Melalui klub ini, siswa dapat belajar bersama, berdiskusi, dan mengembangkan kemampuan coding secara terarah.

Selain menambah wawasan teknologi, Coding Club juga melatih siswa untuk berpikir logis, bekerja sama dalam tim, serta menghasilkan proyek nyata yang dapat digunakan sebagai portofolio di masa depan.

Apa yang Dipelajari

  • CSS
  • JavaScript
  • Pemrograman Web
  • Git dan GitHub
